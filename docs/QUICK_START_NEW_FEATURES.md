## 📦 FILE CHUNKING - Quick Guide

### What It Does
Breaks large files into small chunks for uploading

### Chunk Sizes
- **256 KB** → Mobile networks (slow)
- **512 KB** → Recommended for most users
- **1 MB** → Fast desktop
- **5 MB** → Very fast (WiFi)

### How to Use
1. Go to Dashboard
2. Look at left sidebar
3. See "File Chunking" section
4. Current size: 512 KB
5. Click "Show all options" to change
6. Upload file - auto-chunks!

### Benefits
✅ Resume interrupted uploads  
✅ Better mobile experience  
✅ Real-time progress  
✅ Lower memory use  

---

## 🔐 ENCRYPTION - Quick Guide

### What It Does
Encrypt files so only people with the key can read them

### How to Enable
1. Go to Dashboard
2. Look at left sidebar
3. See "Encryption" section
4. Click "Enable"
5. Key auto-generated!

### How to Use
```
ENCRYPT:
Upload file → SmartCloud encrypts → Share safely

DECRYPT:
Download encrypted file → Enter key → File unlocks
```

### Benefits
✅ Military-grade AES-256  
✅ Only you have the key  
✅ Server never sees plaintext  
✅ Secure file sharing  

---

## 🔑 ENCRYPTION KEY

### What Is It?
32-character random string that unlocks your file

```
Example: a3f2b8c9d1e4f2g3h4i5j6k7l8m9n0o1
```

### Where to Find It
1. Enable encryption (see above)
2. You'll see the key displayed
3. Click eye icon to show/hide
4. Click copy to copy to clipboard

### How to Share Safely
```
❌ DON'T: Send in same email as file link
✅ DO: Send via different channel (SMS, chat, phone)

Example:
- Send file link via: Email
- Send key via: WhatsApp
- Send key via: SMS
- Recipient has BOTH → Can decrypt
```

### Key Safety
🔐 Store in password manager  
🔐 Or keep in safe place  
❌ Don't lose it (can't recover)  
❌ Don't share with others

## ❓ FAQ

**Q: Will chunking slow down my upload?**  
A: No! It's same speed or faster.

**Q: Is encryption secure?**  
A: Yes! AES-256 is military-grade.

**Q: Can I use both chunking and encryption?**  
A: Yes! They work together perfectly.

**Q: What if I lose my encryption key?**  
A: File stays encrypted forever. Keep key safe!

**Q: Can I share encrypted file with many people?**  
A: Yes, but share different key to each group.

**Q: Does server store my key?**  
A: No! Key stays on your device only.

**Q: Can I change chunk size later?**  
A: Yes! Change anytime in left sidebar.

**Q: Does encryption work on mobile?**  
A: Yes! Works on all devices.
